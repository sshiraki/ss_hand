# hand3d v11 — 親指CMCをボールジョイント化

2026-11-08、本人の方針転換による設計変更。
「2つの頬で挟むより、この位置でボールジョイントにするか、
上下左右の自由度を持つジョイントを実装したい」

変更は **手根ベース＋親指中手骨の2部品**。鞍部ブロックは廃止（全20部品に）。
他の18部品はそのまま。再印刷はこの2点。

## 構造
関節中心 C は従来と同じ位置。中手骨の付け根を Ø13 のボールにし、
ベース側は受け（ソケット）にした。ピンもブロックも無い。

- **ボール（中手骨側）**: 球 r=6.5（中心 C）。首（ネック）は r=2.8 の
  細い部分を持ち、そこから骨幹へ広がる。軸部は v9 のまま流用し、
  MCP の位置（C から 48.5mm）も不変なので基節・末節はそのまま付く。
- **ソケット（ベース側）**: 外形 r=8.75 のカップが手根クラスタと
  掌プレートに融合（重なり約330mm³、支持の脚は不要）。
  内面は r=6.75（ボールとの隙間 0.25）。
- **抜け止め（スナップ式）**: 受け口は静止軸から 70° で絞ってあり、
  口の径 Ø12.68 ＜ ボール Ø13。縁に軸方向のスリット6本（幅1.5mm）を
  入れてあるので、ボールを押し込むと縁が開いてはまり、はまると
  抜けなくなる。組立は「押し込むだけ」。
- **可動範囲**: 首 r2.8 と受け口 70° の組合せで、骨軸の傾きは
  **全方向に約45°**（実測: 12方向すべてで 45° まで干渉 0.00、
  50° で首が縁に当たって止まる）。上下左右に加えて、軸回りの
  ねじりも自由（鞍関節には無い自由度。腱と戻しゴムの張力で
  向きはある程度決まる。必要なら回転ガイドは後付け可能）。
- **親指の腱トンネル**: ボール（r6.5）に当たらないよう、ベース内の
  親指トンネルを掌側オフセット 6.5 → 8.3mm に移動。カップ外壁に
  浅い溝を彫る形で通り、ガイドへは空中で合流する（人の母指球の
  上を腱が通る形に近い）。検証で経路の残材料 0.000mm³ を確認。

## 検証（verify_v11.py / check_tendon_paths.py）
- 全20部品 水密・単一ソリッド
- 4指: 連動屈曲の指同士干渉 最大 0.10mm³、中手骨×ベース 0.00（従来どおり）
- 傾き掃引: 12方向すべて最大クリーン傾き 45°
- つまみ姿勢（v10 で検証した5姿勢＝そのまま使える向き）:
  骨軸の傾きは 31〜37° で範囲内。4姿勢は完全クリーン。
  最も深い1姿勢（IP80°＋人差し指 t=0.85）だけ、親指先が人差し指の
  中節骨に 0.65mm³ 触れる — これは v10.3 でも同じ値で出ていた
  既存の軽い接触で、ボール化とは無関係。
