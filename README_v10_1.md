# hand3d v10.1 — ベース改修（全面丸み＋腱トンネル）

2026-11-08。v10 からの変更は **手根ベース1部品だけ**。他の20部品
（4指16＋親指の基節・末節・中手骨＋鞍部ブロック）は v10 のまま使える。
印刷し直すのはベースだけ。

## 変更1: palm plate を全面丸みに（本人の指摘「右端だけ妙に角張っている」）
- 原因: v10 の palm plate は直方体（49×28×9mm）で、小指側（+X）の端が
  手根骨クラスタ（楕円体の集まり）より外に四角く突き出していた。
- v10.1: 外寸は同じまま、角の丸み R9（平面）＋厚み方向の縁 R4 の
  「丸い板」に変更。3つの角丸押し出し形状の交差で作っている
  （generate_base_v10_1.py の rounded_plate）。右端だけでなく全周が
  指骨（楕円体ベースの造形）と同じ丸みになった。
- 体積: plate 12.35 → 10.95cm³。フォーク・ピン穴・手首まわりは不変。

## 変更2: 各指の屈筋腱トンネル Ø2.0（本人の追加指示）
指骨側のガイド穴（Ø1.8）は従来どおり。今回足したのは、糸が手首側から
ベース（手根クラスタ）を通って中手骨のガイド穴まで届くための通り道。
- 4指: 各指の中手骨の腱ライン（骨軸から掌側へ r_guide だけオフセット、
  扇状配置の角度に平行）をそのまま延長し、手根クラスタを貫く
  Ø2.0 トンネルにした。ガイド穴 Ø1.8 に対して +0.2 は、
  最長約14mmのトンネルに糸を通しやすくするため。
  - 人差し指 r=5.75／中指 6.0／薬指 5.75／小指 5.3mm（各指の MCP カム半径）
  - 人差し・小指の軸は M3 取付穴（x=±14）に 0.07mm³ だけ接するため、
    0.3mm 外側へずらして回避（ガイド穴との角度差は 0.6° 程度で実用上無視できる）
- 親指: 静止姿勢の中手骨軸に沿い、腱ライン（CMC 中心から掌側 6.5mm）を
  通る入口トンネル。ベースに固定された入口で、CMC が動くと糸の角度が
  変わって滑る（人の手根管と同じ考え方）。
- 検証（check_tendon_paths.py）: 手首側入口 → 中手骨ガイド穴までの
  Ø1.4 テストラインで、5指とも経路上の残材料 **0.000mm³**（通り抜け確認）。
  トンネルと M3 穴の重なりも 0。

## 検証（verify_v10.py、v10 と同一結果）
- 全21部品 水密・単一ソリッド
- 4指の連動屈曲で指同士の干渉 最大 0.10mm³、中手骨×ベース嵌合 全指 0.00
- CMC グリッド 64/90 セルが干渉 ≤0.30mm³（実用域 軸1 −50〜+20°・軸2 −20〜+50°）
- つまみ姿勢2件も v10 と同一（詳細は README_v10.md / v10 の記録を参照）

## 親指CMCの構造（cmc_explain.png）
- 構成は3部品のサンドイッチ: ベース側フォーク（軸1ピン Ø2.2）／
  鞍部ブロック（橙、直交する2つのピン穴）／親指中手骨側フォーク（軸2ピン Ø2.2）。
  2本のピンは CMC 中心 C で直交し、ユニバーサルジョイントとして働く
  （鞍関節相当の2軸）。
- 内側への回り込み（対向）: 軸1の回転で親指全体が掌の内側へ振れ、
  軸2の回転で指先の向きが回る。静止姿勢に回内45°を組み込み済み。
  実メッシュ検証では CMC(−25°, +28°)・親指の関節は伸展のまま・
  人差し指連動屈曲 t=0.65 で親指先が人差し指先に接触（他の干渉 ≤0.11mm³）。
  つまり「内側に回り込んでつまむ」動きはこの構造でできる。
- 組み立てるとブロックとピンはフォークの中に隠れて外からはほぼ見えない。
  印刷後に動きを確かめる時は、ピン2本を入れる前にブロック単体で
  両フォークに当ててみると構造が分かりやすい。
